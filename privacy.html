プライバシー ポリシー（desk）

最終更新: 2026-10-19

使う人

desk は開発者本人だけが使う個人用の道具です。本人以外のアカウントでは使いません。

読むデータ

本人が許可した本人の Gmail アカウントについて、Gmail API の読み取りの権限（gmail.readonly）で、受信したメールの差出人・宛先・件名・日時・本文を読みます。

使い方と置き場

読んだメールは、返事に判断が要るかを本人に知らせるためだけに使います。データは本人が管理するコンピューターにだけ保存し、本人の Discord に要点を知らせます。

第三者への提供

読んだデータを売ったり、広告に使ったり、第三者に渡したりしません。Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

消し方

Google アカウントの「サードパーティ製のアプリとサービス」から desk のアクセスをいつでも取り消せます。保存したデータは本人が消します。

Privacy Policy (desk)

Last updated: 2026-10-19

desk is a personal tool used only by its developer. With the developer's permission, it reads the developer's own Gmail messages (sender, recipients, subject, date and body) through the Gmail API read-only scope (gmail.readonly), only to tell the developer which messages need a decision. Data is stored only on computers the developer controls, and summaries are sent to the developer's own Discord. The data is never sold, used for advertising, or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account's third-party apps settings. Contact: ywork20261019@gmail.com
